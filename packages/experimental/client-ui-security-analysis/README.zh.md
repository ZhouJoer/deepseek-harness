# @deepseek-ai/dsh-experimental-client-ui-security-analysis

[English](README.md) | 中文

## 概述

选择材料、描述目标即可开始分析，默认选用本机环境。任务及已提交的发现、证据和报告在重启后保留。聊天回复与生成文件只有经过明确采集或记录提交，才会进入对应列表。这个可选面板保留普通对话和工具卡片；需要时可展开资产、检查、环境与复核控制。所有操作经安全领域服务核对权限。可在工具箱页面配置本机外部工具。

在任务首页使用**添加材料**选择文件、文件夹，粘贴文字或导入本机路径，系统会自动识别类型。新建分析会暂存所选材料，点击开始分析时创建任务并保存材料，首页列出已添加的材料。**管理分析任务**支持改名和移除；移除会停止工作并隐藏项目，同时保留证据和报告，可在侧栏的**已移除分析任务**中恢复。恢复后需明确恢复运行才会继续。列表中的长名称会缩短显示，悬停可查看完整名称。

## 使用

新分析需要已保存资源设置或 Host 的 `taskIntake.maxAttempts` 提供工作区尝试次数。缺少次数时，创建页打开工作区资源表单，保存设置前禁用开始分析。高级工作台共用相同表单和次数。

开始前可一次多选或分批添加文件；选择清单列出全部文件名，并共用上传额度。拖动助手左边缘，或聚焦分隔条后使用左右方向键，可调整宽度。**展开至整页**和**恢复分栏**保留对话草稿。任务的**计划审批**按钮直接打开已保存的验证计划；存在待批准计划时显示提示。查看操作、影响和清理方式后，选择**批准此版本**，再点击**执行计划**。列表为空时，助手需要先保存验证计划。

审批卡片分别标明待验证内容、预期观察、实际运行位置、影响和清理方式。参数、版本哈希及完整执行记录可展开查看。审批与执行状态分别显示；执行失败后刷新已保存的结果。离线 Python 即使选择本机环境，也在 Linux 容器内运行。它读取 `/input/source` 下的导入快照，不能直接读取本机 Windows 路径，也不能原生加载 Windows DLL。失败计划需要按实际运行环境更正后重新审批；批准本身不会修复缺失文件。手动准备计划仍位于**发现**页。

本机 Python 计划在审批前显示 Host 操作系统、固定的解释器与版本、工作目录和本机权限范围。Windows 本机验证应选择此工具，并提交完整 Python 代码。本机计划使用当前文件，不提供 Docker 隔离。离线计划改为本机执行时，需要新建计划并审批。

在专用 profile 中按顺序组合 `@deepseek-ai/dsh-base`、应用 bundle、`@deepseek-ai/dsh-experimental-security-profile`。Web 还需在最后加入 `@deepseek-ai/dsh-experimental-security-web-profile`。使用 `dsh --profile <name>` 启动。详见[安全分析](../security-analysis/README.zh.md)。

工具箱的**分析脚本**标签展示内置流量、MQTT 和原生进程观察脚本。可搜索名称、用途或依赖，按分类筛选，展开查看分析思路、参数、安装路径、示例、输出和限制。浏览无需选择项目或环境，不检测或执行工具。关联技能向 Agent 提供同一组资源；执行及输出规则见[脚本库](../security-analysis/README.zh.md#use-this-package)。

从侧栏的**安全分析**或输入框附近的紧凑**安全工作台**入口打开 Dashboard。工作台展示任务数量、名称与目标搜索以及状态筛选。**新建分析**先选择工作区，再暂存可选的文件、文件夹、文字或宿主路径；任务与材料保存后，通过新的原生 Session 发送目标。**更多选项**可选择环境。发送失败仅重试发送。任务详情默认打开**调查链路**，旁边保留总览、资产、发现、证据和报告；返回证据列表保留搜索条件，已保存的 Markdown 报告支持版本与格式选择。**分析助手**在右侧展开原生对话；折叠保留草稿，切换任务或离开页面释放会话引用。浏览历史不会创建 Session 或修改任务绑定。没有可访问的协调会话时，**继续分析**显式创建并关联会话。已停止任务需要明确恢复，恢复已移除任务仍保持停止。操作、重连及助手轮次结束后会刷新，也可手动刷新。

**调查链路**连接已保存的材料、检查、研究方向、子任务、观察、发现、验证计划和复核记录。卡片显示标题、摘要和状态。可切换链路图与**列表**，搜索问题或结果，筛选运行中或需要关注的记录，并聚焦某个分支。窄屏初始显示列表。已关联观察默认折叠，点击**展开观察**或搜索时显示。图中只使用已保存的关联：没有关联的历史记录保持独立，缺失的引用会明确提示，不补造节点或连线。

选择记录可查看结果、成立条件和相关工作，再按标题选择关联观察，即可读取保存的原始输出；采集失败或不完整、观察方式及清理信息仍直接显示。标识、哈希和完整记录元数据收进可复制的**技术详情**。已保存的复核属于历史记录，当前结论以发现状态为准。验证计划连接到既有的**计划审批**控制，可继续检查实际影响并批准所展示的版本。

-----

源码文件或目录资产支持在会话工作台清点文件、按行读取和字面文本搜索。证据卡片标记静态观察、离线模拟及设备验证，并显示失败与清理详情。每个研究方向列出已记录的子任务问题、角色、执行状态、返回摘要及主 Agent 对报告的处理决定。展开子任务可查看派工原因、完成条件、证据引用、局限和建议下一步；**查看子会话**打开该一次性任务的原始历史。采纳子任务报告不等于确认发现。没有保存委派记录的方向会提示暂无已记录的子任务；较早的子任务摘要仍保留在高级工作台历史中。

工具箱的**设备**标签打开时读取缓存观测。**检查设备**显式检测所选环境；失败保留上次接口及观测时间。串口卡片显示 COM/PnP 和可取得的 USB 标识，不认证 Tufty、不打开端口。在任务材料中选择 Wi-Fi 或 BLE 和本机环境，点击**分析抓包**或**查看帧**，结果进入既有证据与进度视图。已暂停任务需先恢复，缺少可访问会话的任务需先点击**继续分析**。文件大小直接显示，技术详情保留哈希，原始抓包字节不作为文本呈现。

<a id="understand-the-implementation"></a>
## 实现

<details>
<summary>实现细节</summary>

此包通过 profile patch 或消息输入框的 dock slot 组合能力，不修改默认 profile 或 agent-loop。浏览器通过生成的 Remote 调用领域服务，文案由双语字典提供。安全工具卡片在准备和执行阶段显示运行中，结果详情与错误状态仅在结果记录后显示。委派成功的工具回执显示**已派出**；进展视图跟踪子任务已保存的执行状态和报告处理决定。不发布 invariant companion，因为包只有可撤销的组合或 UI 注册，业务状态由领域服务持有。

调查链路是当前 WorkbenchView 的只读投影，与执行时间线共用 Dashboard 既有的项目活动订阅，仅在选择观察时读取制品预览。浏览链路不产生模型轮次或持久关联。审批和执行仍由既有领域方法负责。

</details>

## 持久安全项目

任务列表提供行内删除确认、进行中状态和收起退场动画，并支持减少动态效果。普通删除可撤销，也可在“已删除任务”中恢复。永久删除入口位于该列表，点击后二次确认即可，且无法撤销。请求失败后保留确认面板以便重试。分析摘要和报告使用简体中文，代码标识和路径保持原样。

工具箱打开时显示定义目录，不运行探测。可搜索用途、按标签和工具包筛选，然后检测单个工具或筛选结果。定义表单、JSON 导入预览与工具包导出无需选择项目或聊天。导入冲突需要显式确认，导入不安装软件、不执行命令。可编辑的本机环境保留可执行文件浏览、参数设置、版本检测和恢复默认配置；检测失败保留原安装配置。活跃会话工作台提供工具与集合软偏好，可恢复自动发现。偏好从下一次模型请求生效，在会话释放后清除。参见[采集指南](../../../docs/user/guide/security-analysis.zh.md)。

侧栏安全分析面板无需选择聊天即可列出项目、目标、检查、发现、复核、报告和靶场实例。历史分析页的高级详情提供显式复用本地镜像和构建新镜像操作，两者都保留已有靶场的镜像标识。聊天工作台可登记已启动 Web 目标、应用独立复核和生成修订报告。两个项目视图均直接排版展示已保存的 Markdown 简报及可选发现附表。[Web 指南](../../../docs/user/guide/security-analysis.zh.md#local-web-laboratory) 说明操作流程与当前 provider 限制。

主聊天页在输入框上方保留紧凑的**工具**计数徽标，点击后在原生右侧栏打开**工具与进展**；侧栏关闭时徽标仍实时更新。未关联任务的会话在侧栏显示明确空状态。窗口通过独立且可释放的流跟踪会话选择和项目活动。任务详情保留**工具与进展**标签，用于查看执行时间线。两个时间线入口都按研究方向展示三行：使用工具、当前结论、下一步或阻碍。多轮研究更新同一段；问题改变后返回侦察会形成独立一段。工具名称和次数仅供参考，同名计数合并，不显示执行核实标签；执行失败与输出不完整状态仍保留。展开后分页查看调用详情及证据标题，调用标识和参数收进技术详情。空状态明确区分未保存的记录和聊天摘要。重连恢复所选项目的快照。侧栏只展示信息。原生输入框保留已有停止按钮；暂停整个项目仍属于工作台管理操作。直接在原生输入框中补充或纠正分析方向；暂停的项目需明确恢复后才能继续分析。


**持续改进**页面汇总所有任务在能力、流程、脚本和方法论上的建议，可搜索并按任务、进度筛选。任务详情提供**改进点**和**立即分析改进点**；任务执行中会排队。展开建议查看问题、引用记录、期望能力和验收方式。可复制 Markdown，或下载包含 `TASK.md`、`proposal.json` 和 `result.template.json` 的 ZIP。手动填写实施回执或导入 JSON，检查结果后再明确确认验证。导入的测试声明不会自动验证建议。忽略的建议可以恢复；已验证建议出现新依据时提示复查。

## 模型体验

### 安全上下文

#### 模型看到的内容

开始分析会将用户填写的目标作为原生对话消息发送；`security_scope` 由领域服务提供。领域工具把模型可见结果记录在 Session 中。

#### Token 影响

领域工具定义和检索到的证据按配置的输出限额占用上下文。此包不改变 token 统计。

#### KV Cache effect

固定工具定义和工作流指引保持稳定；项目状态通过已记录的工具结果进入上下文。

## 已知限制与后续工作

<a id="known-limitations-and-deferred-work"></a>

- 调用详情按页读取，需要刷新才能查看后续调用。任意脚本内部的具体工具执行无法核实；后台输出未完整收集时保留不完整标记。外部工具和环境验收限制见[安全分析](../security-analysis/README.zh.md)。
